# CertAtlas

IT資格の学習サイトです。カタログから資格を選び、専用の学習室で演習と復習に取り組めます。

公開URL　[https://shikaku-atlas.neatsaffron.chatgpt.site](https://shikaku-atlas.neatsaffron.chatgpt.site)

閲覧には、利用権限のあるChatGPTアカウントでのログインが必要です。

## 問題データ

- `data.js` … 資格カタログ(資格IDは並び順で決まるため、追加は各グループの末尾に)
- `data/bank-index.js` … 資格ごとの問題数(カタログ表示用)
- `data/bank/<資格ID>.json` … 問題本体。学習室を開いたときに読み込む
  - `type`: single / multiple / fill(入力式) / written(記述式・自己採点)
  - `why`: 選択肢ごとの解説。`mark` は選択肢中の誤っている部分(画面で赤い波線を引く)、`reason` はその説明
- 収録元: IT資格統括サイト用データ(各資格20問のオリジナル想定問題)、LPIC 学習ルームの模擬試験348問(LPIC-1)、既存の基本問題

## 演習画面の操作

- 選択肢を選んだ直後に正誤と解説を表示(複数選択は指定数を選んだ時点)
- 画面上部の番号で各問題の合否を色表示(緑=正解・赤=不正解・灰=未回答)。押すとその問題へ移動
- キー操作: 1〜5 で選択、Enter で次の問題、← → で問題を移動

## 更新履歴

### 2026-11-19 学習計画(最短合格プラン)と試験予約リンク

- **学習計画(`#plan`)** を各資格の学習室に追加(ワークスペースの「学習計画」、学習ホームの「最短合格プラン」カードから開く)。AWS Architecture Academy の学習計画と同じ設計
  - 入力: 1日の学習時間 / 教材インプットの時間(資格の難易度から目安を自動入力・変更可) / 受験予定日(空 = 最短) / 休みの曜日
  - 計算: 「教材インプット＋問題集1周(問題集はインプット期間に分散、誤答の復習を2割混ぜる)」→「弱点復習(誤答数×1.3)」→「模擬試験(模擬セットごとに1日。無い資格は問題集の通し解き)」→「模試の復習」→「最終確認」→ 受験日。これまでの回答結果(未回答数・誤答数・正答率)を反映
  - 受験日を指定した場合は、収まるまで1日の学習時間を増やし(上限10時間)、余った日は総合演習で埋める。日数が足りない時は仕上げを優先して警告を表示
  - 表示: 最短の受験日・学習日数・総学習時間のプレビュー、フェーズの内訳、今日のタスク(問題集・模試をその場で開始)、日別の計画と完了チェック
  - 保存: `state.plans[資格ID]`(localStorage `shikaku-atlas-v1`)。カタログのカードに「受験予定日」を表示
- **試験予約リンク**: 学習室ワークスペースに「試験を予約する ↗」を追加(新しいタブ)。資格ごとの公式予約・申込ページは `data.js` の `bookingSites`(2026-11-19 確認)。追加した資格は登録時の公式サイトURLを使う
- スマートフォンでワークスペースメニューの項目が横並びに潰れていた表示を縦並びに修正
